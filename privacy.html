Atlas — Privacy Policy

Last updated: 30 September 2026

Who uses Atlas

Atlas is a private personal assistant built and used only by its developer, Michele Meloni. It has no other users and no public sign-up.

Google data accessed

  • Google Calendar (read and write): to list, create, move and delete the developer's own calendar events when he asks.
  • Gmail (read-only): to read recent messages in the developer's own inbox and decide whether something important deserves a reminder. Atlas never sends, deletes or modifies email.

How the data is used and stored

  • Data is used only to provide the assistant features described above to the developer himself.
  • Short excerpts (such as sender, subject and a message summary) are stored in a private database on the developer's own computer or private server.
  • To understand requests, excerpts are sent to the Anthropic API (Claude language models). Anthropic does not use API data to train its models.
  • Data is never sold, never used for advertising and never shared with anyone else.

Limited Use

Atlas's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

Access can be revoked at any time from Google Account permissions. Stored data can be deleted by removing the local database.
